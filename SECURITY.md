# Security policy

## Reporting a vulnerability

Email: smigolsmigol@protonmail.com

Acknowledgment SLA: 48 hours.
Critical-fix SLA: 7 days.

## Scope

This repository is a github profile README + landing page. There is no
runtime, no API, no server-side surface. In-scope reports would cover
phishing-style content, malicious links, or third-party-asset compromise
in the README.

For runtime security questions on f3d1 ecosystem packages, see the
relevant repo's SECURITY.md:

- f3dx: https://github.com/smigolsmigol/f3dx/blob/main/SECURITY.md
- llmkit: https://github.com/smigolsmigol/llmkit/blob/main/SECURITY.md
- f3dx-cache, pydantic-cal, f3dx-router, f3dx-bench, tracewright, keyguard
